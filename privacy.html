Privacy Policy — AlbumDesigner Save Guard

Effective date: 7 May 2026

AlbumDesigner Save Guard ("the Plugin") is a Photoshop UXP companion to the AlbumDesigner desktop application, distributed by Pixsora.

What we collect

Nothing. The Plugin does not collect, transmit, or store any user data, document content, telemetry, or analytics. All operations happen entirely on the user's local machine.

Network use

The Plugin makes no network requests of any kind. It does not contact Pixsora servers, third-party services, or Adobe servers beyond what Photoshop itself does.

Files on disk

The Plugin reads and writes only files inside the user's own AlbumDesigner managed folder (~/.albumdesigner/) for coordination with the AlbumDesigner desktop app, and the file the user is actively editing in Photoshop. No other files are accessed.

Children

The Plugin is not directed at children under 13.

Changes

Updates to this policy will be posted at this URL with a new effective date.
